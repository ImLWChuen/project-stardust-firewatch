# Component Responsibilities

Detailed mapping of system components to team duties and scientific boundaries:
- `science/harmonization`: Algorithmic sensor cross-calibration and index computation.
- `science/anomaly`: Seasonal historical baselines and anomaly thresholding.
- `backend/app`: Fast querying, spatial filtering, caching, and serialization.
- `pipeline`: Scheduled batch transformations and external data syncing.
- `frontend`: High-performance user interface and interactive burning calendar.
